## 🌿 نظرة عامة ورؤية المشروع

**عيادات سكينة (SAKINA)** هو مشروع ويب إكلينيكي رائد تم تطويره وتصميمه ليكون نموذجاً مرجعياً لمواقع العيادات النفسية والمراكز الطبية التخصصية الراقية في العالم العربي.

على النقيض من القوالب الجاهزة المكررة أو التصاميم الطبية الباردة، تم بناء سكينة بناءً على فلسفة **«الملاذ الآمن» (Safe Haven)**:
* **تخفيف حاجز الخوف والتردد:** لغة تحريرية عربية دافئة ورصينة تم صياغتها بعناية لتشجيع طلب الدعم النفسي كخطوة واعية وشجاعة دون أي وصمة.
* **الشفافية الكاملة:** توضيح مراحل الجلسة، المنهج العلاجي، حدود الاستشارة والضوابط الأخلاقية، والخيارات الحضورية وعن بُعد قبل اتخاذ قرار الحجز.
* **الاحترام الفائق للخصوصية:** لا يتم تخزين بيانات المستخدمين في خوادم طرف ثالث، مع نظام حجز تفاعلي يتيح التصدير المباشر والمشفر عبر تطبيق واتساب المباشر للعيادة.

## ✨ أبرز المميزات والوظائف

### 1. نظام حجز تفاعلي من 6 خطوات (`/booking`)
* معالج حجز مرن (`Multi-Step Wizard`) يتيح للمراجع:
  1. اختيار نوع الخدمة أو الاستشارة التخصصية.
  2. تحديد نمط الجلسة (حضورياً بالعيادة أو عن بُعد عبر اتصال مرئي آمن).
  3. اختيار الأخصائي المناسب أو ترك الاختيار التلقائي للأقرب موعداً.
  4. تحديد اليوم والتوقيت الملائم عبر رزنامة تفاعلية حية (Next 12 Days).
  5. تعبئة البيانات الأساسية وتفضيل وسيلة التأكيد (واتساب / اتصال).
  6. مراجعة ملخص الطلب مع إمكانية إرساله بنقرة واحدة لواتساب العيادة أو نسخ الملخص للحافظة.

### 2. انيميشن هادئ ومخصص لكل قسم وتفاعل (`Framer Motion`)
* نظام حركات مدروس (`ScrollReveal`) تم تصميمه خصيصاً للرعاية النفسية:
  * حركات دخول صاعدة ناعمة (`fade-up`).
  * تتابع متدرج للبطاقات والقوائم (`stagger-container` & `stagger-item`).
  * انزلاق جانبي متناسق للمقارنات والمحاور (`slide-right` & `slide-left`).
  * تكبير هادئ يركز انتباه الزائر (`scale-up`).
* مراعاة تامة لتقليل الحركة لأصحاب الحساسية البصرية (`prefers-reduced-motion`).

### 3. تجربة جوال وتابلت متكاملة بنسبة 100%
* **قائمة جوال متطورة (Portal Drawer):** تنبثق عبر `createPortal` مباشرة في الـ `body` مع خلفية عاجية صامتة تمنع أي تداخل أو شفافية أثناء التمرير، مع إغلاق تلقائي للتمرير الخلفي (`overflow: hidden`).
* **شريط حجز عائم للجوال (`MobileStickyCTA`):** يظهر بذكاء أثناء التمرير ويوفر اتصالاً مباشراً وحجزاً سريعاً، ويختفي تلقائياً عند فتح القائمة الجانبية لتجنب أي تداخل بصري.
* **تنسيق متناسق لأجهزة التابلت:** توزيع مثالي لعناصر الهيدر؛ الشعار في الركن الأيمن، وأزرار الاتصال والحجز وأيقونة القائمة مجمعة في الركن الأيسر.

### 4. دليل خدمات إكلينيكية متعمق (`/services` & `/services/[slug]`)
* صفحات مخصصة لكل خدمة علاجية تشمل:
  * الفئات والمؤشرات المستهدفة للجلسة.
  * التسلسل الإكلينيكي لخطوات الرعاية (Roadmap).
  * المنهج والمدارس العلاجية المعتمدة (CBT, ACT, Psychodynamic).
  * الحدود والضوابط الأخلاقية المهنية.
  * الأخصائيون المرتبطون بتقديم هذه الخدمة مع إمكانية الحجز المباشر.

### 5. ملفات الأخصائيين الشاملة (`/specialists` & `/specialists/[slug]`)
* استعراض مسار كل طبيب ومعالج نفسي، مؤهلاته، سنوات خبرته، فلسفته الإكلينيكية، واللغات المتاحة، مع إطار معماري مقوس راقٍ يحافظ على موضع الرأس والملامح بدقة.

### 6. مكتبة معرفية ومقالات تثقيفية (`/knowledge` & `/knowledge/[slug]`)
* مقالات إكلينيكية مبسطة بفهرس محتوى تفاعلي (`Table of Contents`)، شريط متابعة القراءة، تنبيهات طبية توعوية، ومقالات ذات صلة.

### لوحة الألوان (Brand Palette)

| اللون | الدرجة الأساسية | كود Hex | الدلالة الإنسانية والنفسية |
| :--- | :--- | :--- | :--- |
| **Forest Green (الأخضر الغابي)** | `forest-900` / `forest-500` | `#0D1815` / `#29463F` | يمثل الرصانة الطبية، الموثوقية العميقة، والاستقرار النفسي. |
| **Sage Green (أخضر المريمية)** | `sage-500` / `sage-200` | `#8FA38B` / `#CDD9CA` | يرمز للتعافي، وضوح الذهن، والتنفس الهادئ. |
| **Warm Ivory (العاجي الدافئ)** | `ivory-100` / `ivory-50` | `#F7F6F0` / `#FCFBF8` | خلفية مريحة للعين تمنح شعور الملاذ البيتي الدافئ. |

* **خط العناوين والافتتاحيات:** `Alexandria` — خط هندسي عربي حديث بوزن عريض وأنيق يمنح حضوراً واثقاً ومريحاً.
* **خط النصوص والمحتوى:** `IBM Plex Sans Arabic` — خط وظيفي إكلينيكي ممتاز للقراءة الطويلة والأرقام، بدرجات تباين تلبي معايير إمكانية الوصول `WCAG AAA`.

## 🧭 خريطة الصفحات والمسارات

تم بناء الموقع بتقنية **التوليد الثابت الكامل (100% Static Site Generation - SSG)** ليولد **30 صفحة HTML عالية السرعة والأمان**:

| المسار (Route) | نوع الصفحة | الوصف الوظيفي |
| :--- | :--- | :--- |
| `/` | Static (SSG) | الواجهة الرئيسية، رحلة الرعاية، مميزات سكينة، ونبذة الأخصائيين. |
| `/about` | Static (SSG) | قصة نشأة سكينة، الفلسفة الإنسانية، الرؤية، ومساحات العيادة. |
| `/services` | Static (SSG) | دليل الخدمات الـ 6، جدول مقارنة الصيغ (حضوري / عن بعد). |
| `/services/[slug]` | Dynamic (6 SSG) | الصفحات التفصيلية للخدمات: استشارات فردية، قلق، اكتئاب، إلخ. |
| `/specialists` | Static (SSG) | قائمة الأخصائيين مع تصفية فورية حسب التخصص ونمط الاستشارة. |
| `/specialists/[slug]` | Dynamic (4 SSG) | الملف الكامل لكل طبيب ومعالج مع ارتباطات الحجز المباشر. |
| `/knowledge` | Static (SSG) | منصة التثقيف النفسي، محرك بحث فوري، وفلترة حسب الأقسام. |
| `/knowledge/[slug]` | Dynamic (6 SSG) | نصوص المقالات الكاملة مع فهارس متحركة وشريط القراءة. |
| `/contact` | Static (SSG) | أرقام التواصل، العنوان، الخريطة، ونموذج الاستفسار السريع. |
| `/faq` | Static (SSG) | أكورديون تفاعلي مصنف للأسئلة الشائعة مع حقل بحث داخلي. |
| `/booking` | Client (SSG) | معالج حجز مواعيد تفاعلي متكامل بدون خوادم خارجية. |
| `/privacy` | Static (SSG) | ميثاق السرية المهنية وأخلاقيات حفظ البيانات الطبية. |
| `/sitemap.xml` & `/robots.txt` | Generated | التوافق الفوري والأمثل مع محركات البحث (SEO). |

## 💻 التقنيات المستخدمة

* **إطار العمل الأساسي:** [Next.js 14](https://nextjs.org/) (App Router Architecture).
* **لغة البرمجة:** [TypeScript 5](https://www.typescriptlang.org/) بنظام كتابة وتدقيق أنواع صارم (Strict Typing).
* **تنسيق الواجهات:** [Tailwind CSS 3.4](https://tailwindcss.com/) مع فئات مخصصة للأقواس المعمارية والظلال الناعمة.
* **محرك الحركات والتفاعلات:** [Framer Motion 11](https://www.framer.com/motion/) مع دعم كامل لمعايير تقليل الحركة.
* **الأيقونات:** [Lucide React](https://lucide.dev/) لتوفير أيقونات طبية وواجهات نظيفة ومتسقة.
* **الخطوط ومحركات الخط العربي:** Google Fonts (`next/font/google`) بدون حظر أو بطء في التحميل.

## 🚀 خطوات التثبيت والتشغيل المحلي

### المتطلبات الأساسية
* بيئة تشغيل **Node.js** (الإصدار `18.17.0` أو أحدث).
* مدير الحزم **npm** أو **pnpm** أو **yarn**.

### 1. استنساخ المستودع (Clone Repository)
```bash
git clone https://github.com/your-username/sakina-clinic.git
cd sakina-clinic
```

### 2. تثبيت الحزم (Install Dependencies)
```bash
npm install
```

### 3. تشغيل خادم التطوير المحلي (Run Dev Server)
```bash
npm run dev
```
افتح المتصفح وتوجه إلى الرابط: [http://localhost:3000](http://localhost:3000)

### 4. بناء نسخة الإنتاج والتحقق (Build for Production)
```bash
npm run build
```
سيقوم Next.js ببناء كافة الصفحات وتوليد الـ 30 صفحة الثابتة بنجاح، مما يؤكد خلو المشروع من أي أخطاء.

### 5. معاينة نسخة الإنتاج محلياً (Preview Production)
```bash
npm run start
```

## ⚡ الأداء وسرعة التحميل وإمكانية الوصول

* **SEO جاهز بالكامل:** دعم مدمج لـ `Metadata` التلقائية لكل مسار، مع وسمات Open Graph، وتوليد ديناميكي لملف `sitemap.xml` و `robots.txt`.
* **سرعة استجابة فائقة (Instant TTFB):** كافة الصفحات مسبقة التوليد (`SSG`) بدون استعلامات قاعدة بيانات بطيئة.
* **صور محسنة:** استخدام مكون `next/image` مع أحجام متجاوبة (`sizes`) ونسب أبعاد ثابتة لتجنب أي إزاحة تراكمية للتصميم (`CLS = 0`).
* **معايير إمكانية الوصول (Accessibility):** تباين لوني مدروس يطابق معايير `WCAG AAA`، مع عناصر دلالية `Semantic HTML5` (مثل `<header>`, `<main>`, `<article>`, `<nav>`) وتسميات واضحة لقارئات الشاشة.
